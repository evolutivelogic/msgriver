# Governance

MsgRiver is a maintainer-led open-source project sponsored by Evolutive Logic.

Maintainers set product direction, adjudicate specification and security decisions, review
contributions, and publish releases. Decisions prefer documented user outcomes, operational
evidence, and long-term maintainability over vote counting. Material decisions and unresolved
dissent are retained in the repository review ledger.

Contributors can earn broader review and maintenance responsibility through sustained, high-quality
work. Governance will be revised before adding maintainers outside Evolutive Logic.
