# Code of conduct

MsgRiver contributors and maintainers commit to a professional, respectful, and harassment-free
project environment regardless of identity, background, experience, or viewpoint.

Expected behavior includes constructive technical disagreement, clear evidence, respect for privacy,
and accountability for mistakes. Harassment, threats, discrimination, deliberate exposure of private
information, and sustained disruption are unacceptable.

Maintainers may edit or remove contributions and restrict participation when necessary to protect
the project community. Report conduct concerns privately through the repository owner's GitHub
profile. Reports will be handled discreetly and without retaliation.
